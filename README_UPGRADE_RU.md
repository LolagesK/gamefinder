# GameFinder PC v0.4.1 — обложки, информация об играх, популярность

## Кратко

* Уже импортированные 210 669 игр НЕ УДАЛЯЮТСЯ. Старые и новые записи D1 остаются на месте.
* Сортировка «Сначала популярные» доступна в каталоге. По умолчанию популярные игры тоже приоритетнее неизвестных записей.
* Рейтинг популярности — ОЦЕНКА SteamSpy по владельцам/онлайну/активности, а НЕ официальный показатель Valve.
* Игра с неизвестными характеристиками остаётся с пометкой «Нет данных», характеристики не выдумываются.
* Для видимых карточек пробуются два CDN Steam (новый путь и старый). Если официальный ресурс отсутствует, показывается аккуратная обложка-заглушка.
* Новый GitHub Actions workflow обновляет данные SteamSpy и несколько десятков карточек из официального Steam Store ежедневно.
* Статистика числа игр хранится отдельно; обычное открытие каталога больше не пересчитывает всю D1 базу.
* Для публичного Worker доступны только запросы чтения. Токен Cloudflare остаётся исключительно в GitHub Secrets.

## КАК ОБНОВИТЬ ТВОЙ РЕПОЗИТОРИЙ БЕЗ РИСКА ДЛЯ D1

1. В папке с загрузками распакуй `GameFinder_PC_v0.4.1_GITHUB_SAFE_PATCH.zip`.
2. Открой https://github.com/LolagesK/gamefinder и убедись, что выбрана ветка `main`.
3. Нажми `Add file` → `Upload files`. Перетащи **содержимое** распакованного архива, сохраняя подпапки. Не перетаскивай сам ZIP.
4. Сделай `Commit changes` → напрямую в `main`.
5. Дождись успешной публикации в Cloudflare → Workers & Pages → gamefinder-pc-catalog → Deployments.
6. Открой https://gamefinder-pc-catalog.artem-kostromin-05.workers.dev/api/catalog/meta — ожидается `version: "0.4.1"`, `mode: "d1"`. Количество игр не должно уменьшиться.
7. Открой GitHub → Actions → **Enrich Steam games and update popularity** → **Run workflow**.
8. В логе шага должно появиться `ENRICH DONE`; в `/api/catalog/meta` появится `enrichmentStatus.ranked` (>0), а каталог начнёт показывать популярные игры сверху.

### Важно про скрытую папку `.github`
Если после загрузки нового архива workflow не виден во вкладке Actions, проверь файл
`.github/workflows/enrich-steam.yml` в GitHub. Если файл отсутствует, создай его
через `Add file → Create new file` с точным путём `.github/workflows/enrich-steam.yml`
и вставь содержимое одноимённого файла из архива. Затем Commit changes.

### Почему безопасный архив лучше полного
Полный архив (`GameFinder_PC_v0.4.1_CLOUDFLARE_FULL.zip`) содержит `wrangler.jsonc`
с заглушкой `PASTE_DATABASE_UUID_HERE`. Твой репозиторий уже содержит НАСТОЯЩИЙ ID.
При обновлении существующего сайта **НЕ ЗАМЕНЯЙ `wrangler.jsonc`**.
Безопасный PATCH специально **НЕ СОДЕРЖИТ `wrangler.jsonc`**, поэтому его нельзя случайно затереть.

## Данные и ограничения

* SteamSpy API предоставляет приближённые показатели. Они могут запаздывать и не охватывают всю базу; ранжированные игры показываются сначала, остальные — далее.
* При первом запуске GitHub Actions обрабатывает несколько списков SteamSpy (включая одну очередную страницу из примерно 1000 игр, постепенно проходя весь доступный список SteamSpy).
* SteamSpy просматривает очередную страницу примерно из 1000 записей за запуск. Рейтинг и общественные теги появляются у всё большей части каталога, насколько позволяет источник.
* Из официального Steam Store процесс запрашивает до 45 игр за успешный запуск по умолчанию, сначала популярные, затем остальные. Данные по 210 тысячам игр НЕ появятся мгновенно. Официальный Store может ограничивать доступ/частоту запросов.
* Цены получаются из магазина NL в EUR, а не вычисляются из USD SteamSpy. Цена и наличие изображений могут быть недоступны для некоторых игр/регионов.
* В карточках появился примерный показатель отзывов SteamSpy (отмеченный `SteamSpy`); это не подмена подтверждённого рейтинга Steam.
* Скрипт сохраняет уже заполненные вручную жанры и описания, заполняет преимущественно пустые поля.
* Источник 210 тысяч AppID — сторонний список; часть названий может быть недоступной в магазине Steam и не иметь официальных обложек.
* По расписанию `enrich-steam.yml` запускается ежедневно в 04:10 UTC. Настроенные ранее три GitHub Secrets (`CLOUDFLARE_*`) повторно создавать не нужно.
* Если SteamSpy временно недоступен, workflow покажет ошибку, а D1 продолжит обслуживать сайт.
